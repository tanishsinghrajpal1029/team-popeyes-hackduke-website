01 / THE TARGET

Equal amplitudes, one excitation count.

A Dicke state puts equal amplitude on every bitstring with exactly n ones among N qubits. There are K = C(N,n) such strings. The normalization factor matters: their probabilities must add to one.

THE STATE WE MUST PREPARE
|DNn⟩ = 1√C(N,n) Σ|x|=n |x⟩

In the Z basis, a valid bitstring has probability 1/C(N,n); every other string has probability zero. But Z probabilities alone cannot show whether the relative phases are right. The judges also measure in the X basis, where interference exposes phase errors.

ONE IDEAL X-BASIS CHECK
⟨XiXj⟩ = 2n(N−n)N(N−1) for i ≠ j

A pair flip stays inside the Dicke subspace only when those two bits differ. This is one correlator, not the entire X-basis score.

02 / THE HARDWARE

A beautiful state meets an imperfect graph.

The supplied willow_pink connectivity has 105 qubits and 182 possible two-qubit couplers. A circuit cannot ask arbitrary distant qubits to interact. The main task permits CZ gates only on supplied working couplers and single-qubit PhasedXZ gates on working qubits.

Topology

Qubits are vertices; usable CZ couplers are edges. Broken qubits or couplers disappear from the working graph.

Calibration

The runner supplies CZ, single-qubit, and asymmetric readout error dictionaries. Placements can change with those rates.

Limits

A build has under one minute to return. Circuits over 1,750 moments are rejected before the runner adds X-basis Hadamards and final measurements.

That is why an abstract low-gate circuit is only a starting point. It must be placed, compiled into native operations, and checked against the actual working graph.

03 / WHAT WE BUILT

From one recipe to a portfolio.

We built and compared several exact-state constructions. The aim was to keep entangling gates and depth low while preserving the state exactly. Different (N,n) pairs favor different structures, so the combined submission uses a validated selector and a fallback.

01

Simplify the native circuit

We replaced generic controlled-rotation decomposition with explicit CNOT-based patterns, then compiled to the allowed CZ and single-qubit gates. This reduced avoidable two-qubit overhead.

02

Route the construction on the grid

A hub-walk layout moves the active interaction through neighboring qubits and recruits fresh qubits from free grid neighbors. It avoids repeatedly routing a long logical line through SWAPs.

03

Search placements and specialize small cases

We tried several placements on the working calibration graph and kept promising candidates. For small states, offline synthesis and tree-shaped W-state circuits offered shorter exact alternatives.

04

Select a valid family for each case

The combined notebook tries one construction for most main-task pairs and a measured crossover for (7,3) and (9,4). It rejects invalid candidates and tries the other family as a fallback.

THE SYMMETRY THAT SAVES WORK
|DNn⟩ = X⊗N |DNN−n⟩

For more than half the qubits excited, we can prepare the complementary Dicke state and flip every qubit.

IDEAS WE TESTED ALONG THE WAY

Offline angle synthesis gave us exact small-state templates; larger template searches were also run on PSC. We investigated VQE-style optimization as a classical way to find angles, but did not put a hardware VQE loop in the submission: the grader requires an exact returned circuit and hardware is not available during circuit construction. AI assisted research and implementation; the route lab’s alternative path is classical Dijkstra, not a trained AI router.

The website’s selector is an explanation of the combined notebook’s choice rule. It does not run quantum circuits in your browser.

04 / WHY PLACEMENT MATTERS

Fewer gates help, but errors decide.

Two circuits of the same logical size can behave differently on different physical qubits. We used the supplied gate and readout rates to guide placement and compared local noise simulations. One screening model estimates a no-error likelihood by multiplying gate, readout, and idle-survival terms.

A PLACEMENT HEURISTIC, NOT THE JUDGE'S SCORE
Psurvive ≈∏gates g(1−pg)× ∏qubits q[(1−f)(1−r0,q) + f(1−r1,q)]× e−tidle/Teff

Here f = n/N is the ideal marginal chance that a qubit reads 1. The idle time constant is an assumption in a local model, not supplied calibration.

We also tested dynamical decoupling: echo pulses during idle windows can cancel some slow phase drift, while the extra pulses can themselves fail. The tradeoff changed with the assumed noise model, so the page presents it as an engineering choice rather than a guaranteed hardware gain.

05 / FINDING AN ALTERNATIVE PATH

Why a detour can win.

The interactive route lab is a classical illustration of routing, separate from the submission’s full circuit placement. It first removes blocked nodes. It then runs Dijkstra twice: once with unit edge costs for the fewest hops, and once with an illustrative CZ-error cost for each move.

NOISE-AWARE ROUTE COST
C(P) = Σe∈P −me ln(1−pe)

mₑ = 3 for each modeled SWAP before the last edge, and mₑ = 1 for the final CZ interaction.

THE SAME RULE AS A SURVIVAL PRODUCT
arg minP C(P) = arg maxP ∏e∈P(1−pe)me

The logarithm turns a product of survival probabilities into additive edge costs, which Dijkstra can minimize.

06 / HOW WE CHECKED IT

Separate exactness, rules, and noise.

These checks answer different questions. Passing one does not imply the others, and a simulated score is not a hardware score.

01 / IDEAL STATE

Did we make the right vector?

Small circuits were simulated without noise and compared with the target Dicke state up to a global phase. The bonus candidates were checked the same way for all 56 graded pairs.

02 / DEVICE RULES

Could the circuit be submitted?

Our local sweep checked 228 main pairs for native gates, working qubits and couplers, build success, and the 1,750-moment cap under a fresh synthetic calibration.

03 / NOISY ESTIMATE

Which choice might hold up?

Local noise simulations and calibration-based estimates compared candidate placements and constructions. These guided decisions but cannot settle the final hardware ranking.

THE MAIN-TASK SCORE SHAPE
S = 1 / (EZ + EX)

The challenge’s E_Z tests excitation count and uniformity; E_X tests X-basis correlators. The hidden test pairs, correlator cutoff, and hardware calibration affect the final result.

07 / BONUS

When the objective changes, the choice changes.

The bonus allows adaptive circuits but does not require them. It grades depth on Willow-connected exact circuits, with no hardware run. For each eligible pair, the combined notebook builds valid exact candidates and returns the one with fewer Cirq moments.

BONUS CHOICE
d*(N,n) = minc ∈ valid exact candidates depth(c)

The eligible range is 2 ≤ N ≤ 15 and 1 ≤ n ≤ ⌊N/2⌋, giving 56 pairs. A non-adaptive circuit is acceptable when it is shallower.

The site’s bonus bars use checked depth data. A displayed sum of Nn/depth is a local comparison metric; the official bonus awards a point to the shallowest submission for a pair.

08 / MAKING IT VISIBLE

The website and UNO Q.

We built the public site so visitors can change a Dicke state, inspect the Willow graph, compare paths, see the circuit selector, and explore the bonus depths. We then translated the routing and depth displays to the UNO Q’s built-in 8 × 13 LED matrix.

MAPPING GRAPH COORDINATES TO THE MATRIX
pixel(r,c) = 13(r−3) + (c−1)

This maps Willow rows 3–10 and columns 1–13 into 104 LED positions. The website shows the full 105-qubit graph; the matrix shows its central window.

The board runs a classical companion app. It does not perform quantum operations. Its controls at 127.0.0.1:7000 are local to the connected computer; the public website includes a matching browser preview for everyone else.
